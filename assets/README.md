## 格式要求（手写素材）

- PNG 格式，**透明背景**
- 墨色手写（黑色或深灰）
- 分辨率 300dpi 或更高
- 图片周围留适当呼吸空间

## 格式要求（墨韵纹理）

- PNG 格式，**透明背景**
- 画布 2000×2000px
- 手绘墨迹，不规则边缘，浓淡变化
- 墨色（黑色），代码会通过 background-color 着色
