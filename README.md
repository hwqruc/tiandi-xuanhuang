# 色·星 — 中国传统五色

以中国古代"五星·五行·五色"宇宙观为框架的沉浸式色彩体验网页。从星空进入色系，以墨韵晕染切换颜色，每个传统色配有一则文化故事与一组主题配色方案。

## 形式

开场为动态星空背景，五颗主星（岁星、荧惑、镇星、太白、辰星）散落于画面，每颗星以不同光色呼吸闪烁，对应木火土金水五行。星名和开场文字"天地玄黄 宇宙洪荒"均为 **Procreate 手写 PNG**，黑色墨迹、透明背景，保留毛笔笔触的自然飞白与浓淡变化，与机械印刷体形成质感对比。

点击星进入色系后，每个传统色铺满全屏，色名以手写大字居中呈现。底部圆点色盘可切换同系三色——切换时触发墨韵晕染动效：一张手绘墨迹 PNG 作为遮罩，从画面中心向外扩散，模拟水墨在宣纸上洇开的效果，切换在墨韵最浓处完成，然后墨迹消散。再次点击画面任意位置展开叙事面板，以故事 / 配色双栏切换。配色方案将当前颜色与三组搭配色组成四色色卡，主色以光环标记。

布局适配桌面与移动端，移动端底部有星标导航栏。诗词为印刷体直接显示，15 个色名、5 个星名、5 个色系标签、1 张开场字共 26 张手写素材，2 张墨韵纹理用于晕染动效。

## 内容

色彩框架为传统五正色体系——青、赤、黄、白、黑，每系三色共 15 个传统色：

- **青系**：天青、石青、柳綠
- **赤系**：硃砂、胭脂、海棠紅
- **黃系**：鵝黃、秋香、杏黃
- **白系**：月白、霜色、縞素
- **黑系**：玄色、墨色、絳紫

每色配有一首相关古诗词及一段约 200 字的文化故事，从不同维度讲述颜色的来处：天青讲宋徽宗一梦催生汝窑，硃砂讲三千年甲骨涂朱到文天祥丹心，胭脂讲丝绸之路传入红蓝花的审美变迁，月白讲古人对"月光非白"的精微色感，墨色讲"墨分五色"的书画传统。每色另设一组命名主题配色方案（如天青配"雨过天青"、石青配"千里江山"、墨色配"墨分五色"），展示传统色在实际应用中的和谐组合。

## 意义

中国传统色不是 Pantone 色卡上的抽象数值。每一种颜色都是一个文化符号——它的名字本身就是一首诗，它的来历连接着矿物、植物、窑火、诗歌和历史。天青不只是 #8DD4E8，它是一个皇帝梦见的颜色；硃砂不只是一个红色块，它是契刻在甲骨上的第一笔汉字。

手写在这个项目里不是装饰，而是内容本身。当"天青"两个字以毛笔的飞白和墨色浓淡呈现时，字体本身就在说话——它的力道、节奏、呼吸，都在传达这种颜色的气质。这和用字体库打出来的"天青"是两种完全不同的信息。中国传统色诞生于手工时代——矿物研磨、植物浸染、窑火还原——用手的痕迹去呈现它们，才是形式和内容的统一。

项目以星辰为入口，是对中国古代宇宙观的一次微缩：天有五星、地有五方、色有五正、人有五行，万物被纳入一个有序而诗意的系统。从星空到颜色到故事，是"仰观天文—俯察色名—心会文脉"的过程。

## 技术

单页 HTML + CSS + JS，无框架依赖。Canvas 星空、CSS mask 墨韵过渡、事件委托导航。可直接部署到 GitHub Pages 或任何静态服务器。
